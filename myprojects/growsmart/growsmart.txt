## 2. Purpose & Problem Solved

Small training institutes aur course authorities ke paas usually apna khud ka learning platform nahi hota — wo WhatsApp groups, Google Drive ya YouTube links par depend karte hain. Result: no progress tracking, no assessment, no proof of completion, aur paid content ka koi secure access control nahi.

**GrowSmart solves this by providing:**

1. **Structured learning** — random content ki jagah ordered lessons with a defined path.
2. **Access control** — free vs paid courses; content sirf enrolled users ko visible, database level par enforce.
3. **Assessment** — auto-graded multiple-choice quizzes with configurable passing score and attempt history.
4. **Verifiable proof** — course complete hone par unique-ID certificate auto-issue, downloadable/shareable as PDF.
5. **Self-service management** — client ko developer ki zaroorat nahi; poora content admin panel se manage hota hai.

**Target users:** Students / learners (mobile app) and course administrators (in-app admin panel).

## 3. Tech Stack

### Frontend (Mobile + Web)
- **React Native 0.81** with **Expo SDK 54** (New Architecture enabled)
- **Expo Router 6** — file-based routing with typed routes
- **TypeScript 5.9** — strict, fully typed data models
- **React 19**
- **React Navigation 7** — bottom tabs, role-based navigators
- **React Native Reanimated 4** + Gesture Handler — smooth transitions
- **Lucide React Native** — icon system
- **react-native-web** — same codebase se web build

### Backend & Data
- **Supabase (PostgreSQL)** — database, auth, storage, edge functions
- **Row Level Security (RLS)** — 48 policies; role-based access enforced in the database, not just the UI
- **Supabase Auth** — email/password, email verification, password reset via deep links
- **Supabase Storage** — course thumbnails and lesson files/videos (separate buckets with access rules)
- **Deno Edge Functions** — Stripe checkout session creation + webhook handler

### Payments
- **Stripe Checkout** — hosted checkout session, opened via in-app browser
- **Stripe Webhooks** — `checkout.session.completed` / `checkout.session.expired` handled server-side; enrollment unlocks only after verified payment

### Native Modules
`expo-print` (PDF certificate generation) · `expo-sharing` (share/download certificate) · `expo-image-picker` (course thumbnails) · `expo-document-picker` (lesson file uploads) · `react-native-webview` (video + certificate preview) · `expo-web-browser` (Stripe checkout) · `expo-linking` (deep links / auth callback) · `async-storage` (theme + session persistence) · `expo-haptics`, `expo-blur`, `expo-linear-gradient`

### Tooling & Delivery
TypeScript strict typecheck · ESLint (expo lint) · Prettier · **EAS Build** for iOS/Android binaries · Supabase CLI migrations (7 versioned migrations)

## 4. Architecture Highlights

- **Role-based routing** — Ek hi app, do experiences. Login ke baad user ka role (`student` / `admin`) decide karta hai kaunsa route group load hoga — `(student)` tabs ya `(admin)` tabs — with protected route guards.
- **Global data cache layer** — Custom `DataCacheContext` app boot par courses, lessons, enrollments, quizzes, attempts, certificates aur payments prefetch karta hai. Result: screens instantly render hote hain, repeated network calls nahi hote, aur pull-to-refresh se cache sync hota hai.
- **Auth context** — Session persistence, deep-link handling (password recovery, auth callback), aur auto profile creation via a Postgres trigger on signup.
- **Security-first data model** — Har table par RLS. Student sirf apna data padh sakta hai; lessons/quizzes sirf published courses ke liye readable; write operations admin-only. Client-side checks sirf UX ke liye hain — asli enforcement database me hai.
- **Server-verified payments** — Client khud ko paid course me enroll nahi kar sakta. Edge function checkout session banata hai, Stripe webhook payment confirm karta hai, phir enrollment create hota hai.
- **Theming system** — Centralized light/dark palettes with shadow tokens, system-theme detection, aur user override (persisted).

**Scale:** ~11,500 lines of TypeScript/SQL · 27 screens · 11 database tables · 48 RLS policies · 2 edge functions

## 5. Features — Student App

- **Authentication** — Email/password signup & login, email verification, forgot-password + reset flow via deep link
- **Course catalog** — Browse published courses, search, free/paid badges, pricing display
- **Enrollment** — One-tap enrollment for free courses; Stripe Checkout for paid courses
- **Course detail** — Lesson list with lock state, progress bar with completion percentage, attached quizzes
- **Lessons** — Text and video lessons (WebView player), attached downloadable files, mark-as-complete progress tracking
- **Quizzes** — Multiple-choice, auto-scored, configurable passing score (e.g. 70%), per-question answer storage, past attempt history and best score
- **Certificates** — Auto-issued on course completion with a unique certificate ID; in-app preview, export as **PDF**, share/download via native share sheet
- **Dashboard** — Live stats: enrolled courses, lessons completed, quizzes passed, certificates earned; continue-learning shortcuts
- **Profile** — Account details, avatar, theme toggle, logout
- **Dark mode** — Full light/dark theme, system-aware, user-togglable, persisted

## 8. Challenges Solved (case-study talking points)

1. **Paid content that can't be bypassed** — Client-side "isEnrolled" checks are trivial to fake. Enrollment aur payment verification server-side hui (Stripe webhook + edge function), aur content access RLS policies me enforce hua — so even a modified client can't read paid lessons.
2. **PDF certificates without a rendering backend** — Certificate ek styled HTML template se generate hota hai aur `expo-print` se on-device PDF me convert hota hai — no server rendering cost, and it shares straight through the native share sheet.
3. **Perceived performance** — Har screen apni query chala rahi thi to navigation slow lag raha tha. Ek centralized cache context banaya jo boot par bulk-fetch karta hai aur mutations ke baad selectively refresh karta hai — screens ab instantly open hote hain.
4. **One codebase, two products** — Student aur admin experiences alag route groups + ek shared design system se banaye, taake do apps maintain na karni paren.
5. **Deep-link auth flows** — Password reset aur email verification links ko app ke andar handle karne ke liye custom scheme (`growsmart://`) + Expo Linking callback route.

## 11. Ready-to-Use Copy — Long Version (project detail page)

> **GrowSmart** is a production-ready mobile learning platform built for a training authority that needed to move its courses off scattered links and into a real, trackable product.
>
> Built with React Native and Expo for iOS, Android and web from a single TypeScript codebase, the app gives students a structured path: browse published courses, enroll instantly in free ones or pay securely through Stripe Checkout for premium tracks, work through text and video lessons, and validate their understanding with auto-graded quizzes. Progress is tracked lesson by lesson, and once a course is completed the app issues a certificate with a unique verification ID that learners can preview, export as a PDF, and share straight from their phone.
>
> Behind the app sits Supabase and PostgreSQL, where access control is enforced at the database layer through 48 row-level security policies — paid lesson content simply isn't readable by users who haven't been enrolled through a verified payment. The Stripe integration runs through Deno edge functions: one creates the checkout session, another consumes Stripe webhooks and only then grants enrollment, so access can never be granted from the client.
>
> The same app also ships a full admin panel. Administrators create and publish courses, upload thumbnails and lesson files, build quizzes question by question, review every registered user, and monitor all payment transactions — no developer involvement needed to run the platform day to day.
>
> Additional work included a global data-cache layer that prefetches the user's courses, progress and certificates at launch for near-instant navigation, a full light/dark theming system with persisted user preference, deep-link handling for email verification and password recovery, and complete App Store and Play Store submission packages.
